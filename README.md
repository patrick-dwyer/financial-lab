# financial-lab
An application that helps to understand your current or prospective options when deciding on financial decisions.

Current projects include:
- Mortgage Simulator(in progress): Scenario based mortgage estimations

Prospective projects include:
- Retirement Simulator: Calculate retirement incomes and budget.
- Mortgage qualification: Understand qualification for mortgages, differences in lump sum amounts, etc.
- Rent vs Buy comparison: Compare what it looks like for renting or buying a place to live.
