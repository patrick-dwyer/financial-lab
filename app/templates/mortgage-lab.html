Mortgage Lab Help

The intent of this web app is to help users compare mortgage scenarios. You can input information for a mortgage scenario and add change features as described below.

Feature Explanations

+ Add: Button used to add scenarios. Can alter scenario inputs below. Refresh of page will reset back to one scenario.

Lump Sum: A one-time pre-payment applied directly to your principal balance.

Payment Change: A permanent increase or decrease to your interest rate amount.

Calculate: Button used to implement changes to the tool.

Base Mortgage: The foundational terms of your loan (Principal, Rate, Amortization).
